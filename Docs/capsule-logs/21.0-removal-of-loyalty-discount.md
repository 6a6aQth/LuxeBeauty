## Key Changes

In accordance with SDD v7:
1. All client-facing loyalty discount UI elements have been removed across the customer booking form, confirmation page, account page, and admin dashboard.
2. Server-side discount calculation and visit counting during booking confirmation have been completely retired.
3. Automated communications (SMS via Twilio and emails via Resend) no longer reference a 30% discount.
4. Schema field `discountApplied` in `prisma/schema.prisma` is annotated as deprecated/retired for backward compatibility without breaking existing database records.

## Architecture Decisions

- The database column `discountApplied` is kept in Prisma as deprecated/retired with default `false` to maintain full database schema compatibility for historic rows while preventing new application code from interacting with or mutating it.
- Phone number normalization and tracking remains intact for customer identity, visit history lookup, and expenditure tracking.
