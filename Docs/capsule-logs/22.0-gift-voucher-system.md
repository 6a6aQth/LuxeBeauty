## Key Changes & Architecture Decisions
- **Data Model:** `GiftVoucher` holds unique `voucherId`, `purchaseAmount`, `remainingBalance`, `recipientName`, `recipientEmail`, `purchaserName`, `message`, `chargeId`, and `status`. `GiftVoucherRedemption` logs each deduction event with timestamps, amounts, services, and notes.
- **FM-12 Guard:** Payment confirmation wraps DB update in `prisma.$transaction` ensuring atomic activation and receipt logging.
- **FM-13 Guard:** Redemption validates `amountDeducted <= remainingBalance` strictly on the server before mutating balance or creating redemption rows.
- **QR Code & PNG Download:** Uses `qrcode.react` (`QRCodeSVG`) and dynamic `html2canvas` for client-side voucher ticket PNG export.
- **Direct Charge Integration:** Directly integrates with TNM Mpamba (`08`), Airtel Money (`09`), and Bank Transfer without redirecting off-site.
