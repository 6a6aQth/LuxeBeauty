## Architecture Decisions

Both sizes use `public/llogo-mark.png` (white wordmark on black). The full-page wait is a fixed black field, screen-blended mark, and a slow blush glow. The smaller mark inverts that file and multiplies it onto the page, so the black plate disappears on light surfaces. `/Llogo.png` keeps a light gray plate and was not used.

A missing price list shows “The price list will be posted here.” The mark shows only while the price image itself is loading. The image is a plain `img` so the Vercel Blob host does not have to be added to `next.config.mjs`.

## Deviations from SDD

FR-24 names `/Llogo.png`. The black field and the light-page mark both use `/llogo-mark.png`, for the reason above.
